Período da folha

Ex.: início 21 e fechamento 20 → a competência Setembro vai de 21/08 a 20/09. Para o mês cheio, use 1 e 31.

DSR

DSR = total de horas extras ÷ dias úteis × domingos/feriados.

Histórico

Use um repositório privado para os dados (contém salários). Crie um token fine-grained com acesso só a esse repositório e permissão Contents: Read and write.

O link de configuração já leva o token: quem abrir o link uma vez fica com a página configurada naquele navegador. Trate o link como uma senha e envie só para quem pode acessar os dados.

Backup

Salva funcionários, lançamentos, feriados e configurações num arquivo .json (o token não é incluído). Útil para levar tudo para outro computador ou navegador.

Funcionário e competência

Valor da hora = salário ÷ divisor (44h semanais = 220 · 40h = 200). Os dados são salvos automaticamente neste navegador.

Lançamentos

Dia útil: informe as horas extras. Sábado/domingo/feriado: informe as horas trabalhadas no dia. Aceita "2", "2,5" ou "2:30".

Regras aplicadas

Dias úteis (acumulado na competência):
até 25h = 50% · de 25h a 40h = 60% · de 40h a 60h = 80% · acima de 60h = 100%

Sábado, domingo e feriado (por dia):
até 8h = 100% · o que passar de 8h = 150%
